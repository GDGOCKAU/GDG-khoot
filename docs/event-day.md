# يوم الفعالية — تشغيل KAUHOOT

كل شي يشتغل على هذا الماك: قاعدة البيانات (PostgreSQL)، السيرفر (API على المنفذ 3000)، والموقع (المنفذ 5173).
الجوالات تفتح رابط واحد فقط (`:5173`)، والموقع يمرّر الطلبات للسيرفر داخلياً. ما فيه أي IP مكتوب في الكود؛ الرابط يتبع عنوان الماك على الشبكة اللي هو متصل فيها.

> كل الأوامر تُكتب من داخل فولدر المشروع:
> `cd ~/Downloads/kahoot`

---

## قبل الفعالية بيوم

1. **الكود:** تأكد إنك على الفرع الصحيح وآخر نسخة:
   ```
   git switch work/backend-mvp && git pull --ff-only
   ```
2. **كلمة سر الأدمن:** الدخول من `/admin` بكلمة السر فقط. لتغييرها:
   ```
   cd backend && ADMIN_PASSWORD='كلمة-السر-الجديدة' npx tsx prisma/seed.ts && cd ..
   ```
3. **جهّز الكويزات** من `/admin` → Create quiz، وانشرها (Publish quiz). الصور تُرفع كملفات وتُحفظ في `backend/uploads/`.
4. **بروفة كاملة:** شغّل (الخطوات تحت)، وسوِّ جولة بجوالك وجوال ثاني على نفس الواي فاي.
5. **اختبار تحميل سريع** (يسوي كويز مؤقت ويلعبه بـ150 لاعب وهمي ثم يحذفه):
   ```
   ADMIN_PASSWORD='كلمة-السر' node scripts/load-test.mjs http://localhost:5173 150 3
   ```
   لازم تطلع `ALL CHECKS PASSED`.

## يوم الفعالية — التشغيل

1. **الماك:** وصّله بالشاحن، وخلّ الغطاء مفتوح. (السكربت يشغّل `caffeinate` عشان الماك ما ينام طول ما السيرفر شغّال.)
2. **الشبكة:** اتصل بواي فاي الجامعة (أو الشبكة اللي بيستخدمها الحضور).
3. **شغّل:**
   ```
   ./scripts/event-start.sh
   ```
   في الآخر يطبع حالة كل جزء والروابط، مثل:
   ```
     ok    PostgreSQL :5432
     ok    API :3000/health
     ok    Web :5173 (+ proxy to API)
     ok    Mac kept awake (caffeinate)
     LAN     http://10.x.x.x:5173        (admin: http://10.x.x.x:5173/admin)
   ```
4. **اختبر من جوالك** (على نفس الواي فاي، ومو على شبكة الجوال): افتح رابط الـ LAN.
   - إذا فتح الموقع → كمّل للخطوة 5.
   - إذا ما فتح (شبكات الجامعات غالباً تمنع الأجهزة توصل لبعض) → استخدم **الخطة البديلة (Tunnel)** تحت.
5. **على شاشة العرض:** افتح رابط الأدمن **بنفس العنوان اللي بيستخدمه الحضور** (LAN أو رابط الـ Tunnel)، سجّل دخول، واضغط Host على الكويز.
   > مهم: الـ QR على شاشة المضيف يُبنى من عنوان الصفحة المفتوحة. لو فتحت المضيف من `localhost` بيطلع QR فيه `localhost` وما بيشتغل على الجوالات.

### الخطة البديلة: Cloudflare Tunnel (رابط https عام)

يُستخدم إذا الجوالات ما تقدر توصل للماك على الشبكة المحلية. يحتاج إنترنت على الماك.
```
./scripts/event-stop.sh
./scripts/event-start.sh --tunnel
```
يطبع رابط مثل `https://xxxx-xxxx.trycloudflare.com`. افتحه على شاشة العرض (ومنه `/admin`)، والـ QR بيحمل نفس الرابط.

- الرابط **يتغير كل مرة** تشغّل فيها `--tunnel`. شغّله مرة وحدة قبل ما تبدأ ولا تعيد تشغيله أثناء اللعب.
- لو جوال قال "ما لقى الموقع" في أول دقيقة: انتظر 1–2 دقيقة (انتشار الـ DNS) أو جرّب بيانات الجوال.
- كل شي يمر عبر Cloudflare، فيضيف تأخير بسيط (عشرات الملي ثانية). تم اختباره بجولة كاملة.

## إدارة اللعبة (شاشة المضيف)

- **Lobby:** يظهر الـ PIN والـ QR وأسماء اللاعبين أول بأول.
  - **Power-ups off/on:** شغّلها قبل Start إذا تبيها (Double points و 50/50، كل لاعب يستخدم كل واحدة مرة).
  - **Lock game:** يقفل الغرفة؛ ما أحد جديد يقدر يدخل. اضغطه لما يكتمل الحضور.
  - **Start game:** يبدأ (لازم لاعب واحد على الأقل).
- **أثناء اللعب:** كل شي يمشي تلقائياً بوقت من السيرفر (Get ready 3 ث → السؤال → Reveal 5.5 ث → Leaderboard 7 ث → Next 3 ث).
  - السؤال يقفل بدري إذا جاوب الكل.
  - **Skip** ينهي المرحلة الحالية فوراً (السؤال، الـ Reveal، الـ Leaderboard، العدّاد).
- **النهاية:** Team results → Top 3 → Final ranking. اضغط **End game** يرجعك للداشبورد (الإحصائيات وتاريخ آخر استضافة تتحدث).
- **Exit game** أثناء اللعب = إلغاء الجلسة، وكل الجوالات تنقفل.

## كيف أتأكد إن كل شي شغّال؟

| وش تبي تشيك | الأمر / المكان |
|---|---|
| حالة كل الأجزاء + الروابط | `./scripts/event-status.sh` |
| السيرفر يرد | افتح `http://<IP>:5173/health` → `{"status":"ok"}` |
| سجلات السيرفر | `tail -f ~/kauhoot-run/logs/api.log` |
| سجلات الموقع | `tail -f ~/kauhoot-run/logs/web.log` |
| سجلات الـ Tunnel | `tail -f ~/kauhoot-run/logs/tunnel.log` |
| سجل البناء والـ migrations | `~/kauhoot-run/logs/build.log` |
| اختبار تحميل قبل البداية | `ADMIN_PASSWORD='…' node scripts/load-test.mjs http://localhost:5173 50 2` |

## لو خرب شي

| المشكلة | الحل |
|---|---|
| الجوالات ما تفتح رابط الـ LAN | الشبكة تعزل الأجهزة → `./scripts/event-stop.sh` ثم `./scripts/event-start.sh --tunnel`، وافتح المضيف من رابط الـ Tunnel. |
| شاشة المضيف انقفلت أو سويت لها Refresh | افتح نفس صفحة المضيف (`/host/<الكويز>`) **بنفس المتصفح**: ترجع لنفس اللعبة بنفس الـ PIN واللاعبين والمرحلة. |
| جوال لاعب سوّى Refresh أو انقفلت الشاشة | يفتح نفس الرابط/الصفحة: يرجع لمقعده تلقائياً (نفس الاسم والنقاط). |
| لاعب طلع من الصفحة | يُحسب خارج؛ ما يأخّر قفل السؤال. يقدر يدخل من جديد فقط قبل Start. |
| السيرفر وقف (`DOWN` في status) | `./scripts/event-stop.sh` ثم `./scripts/event-start.sh` (أو مع `--tunnel`). اللعبة الجارية ترجع من قاعدة البيانات لنفس السؤال/المرحلة. ملاحظة: استخدام الـ Power-ups في تلك اللعبة ما يُحفظ بعد إعادة التشغيل. |
| `Port 3000 or 5173 is already in use` | `./scripts/event-stop.sh` ثم شغّل من جديد. |
| PostgreSQL `DOWN` | `brew services restart postgresql@17` ثم `./scripts/event-start.sh`. |
| نسيت كلمة سر الأدمن | `cd backend && ADMIN_PASSWORD='جديدة' npx tsx prisma/seed.ts` |
| رسالة "The host has locked this game" | المضيف قافل الغرفة؛ اضغط Unlock game. |
| رسالة "This game has already started" | ما يُسمح بالدخول بعد Start (مقصود). |
| الماك نام | تأكد إن `Mac kept awake` = ok في status؛ خلّه على الشاحن والغطاء مفتوح. |
| الإنترنت/الواي فاي بطيء | كل جوال يحمّل تقريباً 1–2 ميجا (الصور والماسكوتات) أول مرة؛ خلّ الحضور يفتحون الرابط قبل البداية بدقائق. |

## بعد الفعالية

```
./scripts/event-stop.sh
```
يوقف الموقع والسيرفر والـ Tunnel. قاعدة البيانات تبقى شغّالة والبيانات محفوظة (الكويزات، الجلسات، النتائج).
